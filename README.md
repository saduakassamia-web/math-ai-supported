# MathQuiz Master 📐

An interactive, responsive web-based mathematics quiz platform designed for students and educators. Built with clean HTML, Tailwind CSS, and MathJax for advanced mathematical typesetting.

## Features ✨
- **Topic Selection:** Choose from 8 distinct math topics or take a randomized Mixed Test.
- **10 Questions per Topic:** Comprehensive question sets featuring easy, medium, and hard difficulty levels.
- **Instant Step-by-Step Solutions:** Detailed mathematical breakdowns rendered instantly after answering.
- **Dark & Light Mode:** Fully adaptive UI theme switcher.
- **Timer & Score Dashboard:** Tracks overall performance, accuracy percentages, and precise time spent.

## Built With 🛠️
- [Tailwind CSS](https://tailwindcss.com/) - Utility-first CSS framework
- [MathJax](https://www.mathjax.org/) - Beautiful math equation rendering in LaTeX
- [FontAwesome](https://fontawesome.com/) - Icons
